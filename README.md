### 2. Fleet Maintenance | Work Order & Approval Tracker

A simulated business analysis and automation case study for maintenance work-order tracking, overdue monitoring, and approval follow-up.

**Highlights**
- Built an Excel work-order register and operational dashboard using Power Query and PivotTables.
- Documented requirements, approval rules, and nine UAT scenarios.
- Tested a Power Automate Desktop workflow with dynamic row detection and a local summary report.
- Verified the 13-record main-workbook run (13 total / 8 overdue / 2 approvals requiring action).
- Used a separate 14-record UAT copy to validate new-record inclusion, zero-exception scenarios, and refreshed reporting; its dashboard and cost PivotTable reconciled at CAD 13,960.

**Tools:** Microsoft Excel, Power Query, Power Automate Desktop, Business Analysis, UAT
